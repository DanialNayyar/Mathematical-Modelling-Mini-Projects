A modular Python project for sampling, visualising and statistically validating probability distributions.

It includes:
- Custom RNG-based samples
- Empirical vs Theoretical CDF Plots
- Empirical vs Theoretical PDF Plots
- Test file that validates mean and variance
- Clean and modular structure allowing for reuse and extension

This project is designed as a foundational probability engine for future work in stochastic modelling, energy markets, Monte Carlo simulation and quantitative analysis
